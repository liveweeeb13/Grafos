# 🎨 Grafos

**Grafos** is a web extension that allows you to draw directly on any web page, **locally and quickly**.

---

## Installation

### For Google Chrome and Opera

1. Download the **.crx** file from the [latest release](https://github.com/liveweeeb13/Grafos/releases).
2. Open `chrome://extensions` in your browser.
3. Drag and drop the **.crx** file onto the extensions page.
4. Click **Install** to confirm.

### For Firefox 

1. Go to [the Mozilla Add-ons page](https://addons.mozilla.org/fr/firefox/addon/grafos)
2. Click **Add to Firefox**
3. Click **Add**


---

## Settings

Default **keyboard shortcut** is ``Ctrl+Alt+P``

You can customize the **keyboard shortcut** and the **maximum brush size**.
